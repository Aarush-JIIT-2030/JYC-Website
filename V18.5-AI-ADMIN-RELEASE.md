# V18.5 — AI Admin Copilot

This release adds a role-protected AI editorial layer to the JYC Control Center.

### Admin workflow
1. Create the initial draft normally.
2. Use **AI Content Copilot** to polish, quality-check or SEO-check the draft.
3. Apply the suggested draft where supported.
4. Preview the public page.
5. Save or publish through the existing role-based controls.

### Covered workspaces
- Clubs
- Events
- Fest Mode
- Homepage
- Team
- Gallery
- Categories & Interests
- Notifications
- Campus Map
- Overview
- System
- Reviews
- Versions
- Registrations
- Albums

### Security
- The browser never receives the OpenAI API key.
- The `ai-content-assist` Supabase Edge Function requires an authenticated JYC administrator.
- AI is advisory and does not bypass the existing publication/review workflow.
- The prompt explicitly prevents fabricated JIIT/JYC facts.

### Deployment
```bash
supabase functions deploy ai-content-assist
supabase secrets set OPENAI_API_KEY=YOUR_SERVER_SIDE_KEY
# optional
supabase secrets set OPENAI_MODEL=gpt-5.6-luna
```

Then run:
```bash
npm install
npm run build
npm run qa
```
