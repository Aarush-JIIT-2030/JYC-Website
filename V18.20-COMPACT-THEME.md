# V18.20 — Compact JYC Theme

## Product intent

Preserve the V15/V17 JYC identity while following the supplied JYC Website specification: compact public navigation, event-first content, responsive pages, subtle animation, approved beige/black/red/gold palette, and a private admin surface.

## Visual fixes

- Home added to desktop navigation.
- Contact replaces Calendar in the desktop primary nav.
- Planner stays discoverable from More.
- Phoenix centered and given restrained orbital rings/orbs.
- Ecosystem Phoenix is sized to its core so it no longer sits below the orbit.
- Night mode receives a layered star/galaxy atmosphere; light mode stays restrained.
- Contact and map pages no longer reserve excessive vertical space.
- Map gets a compact JYC-themed overlay while keeping OpenStreetMap as the basemap.

## Functional fixes

- Contact form attempts `jyc_contact_submissions` when Supabase is configured and fails gracefully when that service/table is not available.
- Map controls and venue search remain functional.
- Reduced-motion support disables continuous Phoenix/star motion.

## Open-source patterns used

The implementation takes restrained inspiration from React Bits background/orbit patterns and MapLibre's open map styling model, without adding a heavy animation dependency or replacing the existing OSM iframe with a proprietary map service.
