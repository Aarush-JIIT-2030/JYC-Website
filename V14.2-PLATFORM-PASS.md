# JYC V14.2 — Platform Pass

This pass extends V14.1 from a visual/interaction product into a more complete campus platform while keeping the no-fake-content rule.

## Added
- Campus Map page with admin-managed locations and optional embedded map source.
- Public certificate verification page backed by published JYC certificate records.
- Event QR share route and QR action on event details.
- Public digital Fest Pass stored locally on the visitor's device.
- Platform workspace in Control Center for campus locations and certificate records.
- Optional Spline Phoenix scene URL in Homepage CMS; CSS/3D fallback remains available when no scene is configured.
- `/llms.txt` and a public content schema for AI/search discoverability.
- Footer and More-menu links for Map, Certificates and Fest Pass.
- Global search entries for the new platform routes.
- Print-friendly QR view and explicit privacy copy.

## Data model additions
- `campusMap.mapUrl`
- `campusMap.locations[]`
- `certificates[]`
- `homepage.phoenixSceneUrl`

All are optional and default to empty values, so an existing Supabase payload remains valid.

## Important
QR images use a public QR rendering endpoint and encode only public JYC URLs. For a fully self-contained deployment, replace that renderer with a bundled QR generator later.

## QA
The environment used for this packaging pass did not contain `node_modules`, and registry access has previously timed out. Run `npm install` and `npm run build` locally before deployment.
