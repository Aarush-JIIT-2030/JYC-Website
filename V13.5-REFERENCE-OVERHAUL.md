# V13.5 — Reference UI Overhaul

This pass moves the public JYC interface materially closer to the supplied JIIT Youth Club reference while keeping the existing Supabase/CMS data model intact.

## Visual changes
- Reference-style compact desktop header with a circular phoenix brand mark.
- Warm cream light mode and near-black dark mode tuned to the reference.
- Hero composition tightened to the reference proportions: left editorial copy, large phoenix/orbit focal point, network-like CSS background, side annotations and campus badge.
- Homepage “What’s Next” changed to a compact chronological strip instead of the older oversized featured-event treatment.
- Mobile header, theme control, five-item bottom navigation and right-side More drawer aligned to the reference phone composition.
- Admin workspace proportions and surfaces tightened toward the supplied dashboard reference.
- Removed the extra homepage pulse/impact strips from the first viewport so the reference hierarchy is preserved; the underlying dedicated content pages remain available.

## Reliability changes
- Escape closes the desktop/mobile navigation, More drawer and search surface.
- Route changes close transient navigation/search state.
- Existing SPA rewrite, PWA, public download and role-based admin behavior remain intact.

## Research basis
The navigation model follows established responsive navigation guidance: five primary destinations on mobile, with deeper destinations in a drawer, and a temporary drawer on mobile. The implementation also follows the responsive drawer patterns documented by Material Design and shadcn/ui. See the release notes for source links.
