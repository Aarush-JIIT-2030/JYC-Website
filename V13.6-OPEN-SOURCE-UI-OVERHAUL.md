# JYC Website V13.6 — Open-Source UI Overhaul

This release tightens the supplied JIIT Youth Club reference match and improves the public/admin interaction system without adding a third-party runtime dependency.

## Reference fidelity
- Desktop header proportions, compact search, brand lockup and navigation spacing.
- Hero typography, warm light mode, near-black dark mode, phoenix/orbit composition and campus annotation.
- Three-card “What’s Next” event strip modeled on the supplied reference composition.
- Mobile header, five-item navigation and right-side More drawer.
- Admin dashboard sidebar/content proportions and command surface.
- Reference footer capability strip.

## Open-source patterns applied
- shadcn/ui-style composable dashboard/sidebar and command surfaces.
- Radix-style focus management principles and visible keyboard focus states.
- Sheet/drawer interaction pattern for mobile More navigation.
- Motion-style reduced-motion considerations, implemented with CSS so the project stays dependency-light.

## Bug hardening
- Added consistent keyboard focus rings.
- Added reduced-motion handling for new interactions.
- Added safer external-link attributes where missing.
- Reworked homepage event presentation to avoid the oversized featured-card mismatch.
- Preserved existing Supabase/RLS data model and role-based admin behavior.
- No “This Week at JYC” section was added.

## Validation
- Static source/brace/JSON checks are run before packaging.
- Production Vite build remains unverified in this environment because the required Vite package is not available in the local npm cache and registry installation times out.
