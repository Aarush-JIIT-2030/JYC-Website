# V17.3 — Experience Cleanup & Existing-Feature Upgrade

## Goal
Improve what already exists, remove low-value duplication from the primary navigation, and fix a few UX correctness issues without adding another large feature layer.

## Changes

### Homepage simplification
Removed three redundant secondary status strips from the homepage:
- JYC Pulse
- Next Moment countdown
- JYC in Numbers / Impact Stats

The homepage already has live Hero Stats, the next-event plaque, and the Campus Feed. Keeping all of these created repetition. The page now moves more directly from hero → campus feed → ecosystem → content.

### Clubs
- Fixed the club-card action that incorrectly said `Save event`.
- It now correctly uses `Follow club` / `Following`.
- Existing local saved/follow state remains compatible with My JYC.

### Events
- Added `Save event` directly to event detail pages.
- Saving uses the same My JYC storage key as event cards, so the two surfaces stay synchronized.
- Added success feedback when saving/removing an event.

### Calendar
Fixed a usability bug where an event with a start time but no end time could generate a zero-duration Google Calendar event.
- Default event start: 09:00 when absent.
- Default duration: 1 hour when an end time is not supplied.

### Navigation cleanup
Removed technical/low-priority items from primary discovery surfaces:
- Download & self-host from More
- Download & self-host from Search
- Standalone Achievements from Search
- Duplicate Moments route from footer
- Standalone Experience settings from footer
- Standalone Agenda from footer
- Project submission from footer

These remain available through appropriate product contexts where applicable.

### Footer
Reduced the footer's Explore list to the core student-facing product:
Clubs, Discover, Events, Moments, Team, Calendar, Campus Map, My JYC, Projects, Resources and Guide.

## Intentionally NOT added
- No AI chatbot
- No social feed
- No comments/likes
- No gamification
- No extra 3D
- No new major navigation layer
- No production/Supabase QA yet

## QA
Static checks performed:
- package version alignment
- event save integration
- club follow label correctness
- homepage redundancy removal
- calendar duration correction
- native popup scan
- release ZIP integrity

Production browser, Supabase, RLS and deployment QA remain for the final phase after the product build is complete.
