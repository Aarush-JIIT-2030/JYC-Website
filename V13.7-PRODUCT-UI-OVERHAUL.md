# JYC V13.7 — Product UI Overhaul

## Reference direction
- Homepage, clubs, events, gallery, team and admin surfaces now follow the supplied JYC reference board more closely.
- Desktop uses compact product chrome; mobile keeps the five-item navigation + More sheet.
- Dark mode remains the primary visual language; light mode keeps the warm cream variant.

## Product improvements
- Gallery lightbox now supports previous/next controls, keyboard arrows, counter and body-scroll locking.
- Team page adds search and role filters.
- Added a global back-to-top control after meaningful scroll.
- Added richer responsive card layouts for clubs/events/team/gallery.
- Added sticky discovery/event controls on larger screens.
- Added additional reference-style ambient gradients, borders and hover states.
- Kept the implementation dependency-light and compatible with the existing Supabase architecture.

## Open-source patterns consulted
- shadcn/ui Sheet and Sidebar patterns for responsive navigation and admin shell.
- shadcn/ui Command pattern for command/search interaction direction.
- TanStack Table documentation for headless, composable data-table principles; existing admin data surfaces remain custom rather than adding a heavy dependency.

## Notes
- No new UI runtime dependency was added; the project keeps its current React/Supabase stack.
- The visual direction is intentionally derived from the supplied reference, while the implementation remains original.
