# V17.4 — SEO & Discoverability

## Goal
Make JYC maximally discoverable for relevant searches such as JIIT Youth Club, JIIT clubs, JIIT events, JIIT fests and JIIT student activities without keyword stuffing or misleading search engines.

## Changes
- Route-specific titles and descriptions for public pages.
- Dynamic canonical URLs.
- Open Graph and X/Twitter metadata.
- Organization, WebSite, BreadcrumbList and Event structured data.
- Public pages are indexable; account/admin/utility routes are marked noindex.
- robots.txt keeps private areas out of crawl paths.
- Added `llms.txt` describing canonical public JYC pages.
- Added build-time sitemap generation. Set `VITE_SITE_URL` to the production origin, then run `npm run seo:sitemap`. When Supabase public env vars are available, the generator also adds published club/event URLs.
- Added a non-JavaScript public navigation block so the initial HTML contains useful crawlable JYC context and links.
- Improved homepage and route copy around genuine JYC content rather than repeated keyword strings.

## Important
Search ranking cannot be guaranteed. Google determines ranking using many signals. This pass improves crawlability, page understanding, internal linking, structured data and search-result presentation; authority and rankings still depend on the live domain, content quality, links/citations, indexing and user demand.
