# JYC V14.6 — UI Overhaul & QA Pass

## What changed
- Reworked public navigation to six primary destinations plus a predictable More menu.
- Added Discover and renamed Gallery to Moments in primary navigation.
- Added a desktop More popover while retaining the mobile More sheet.
- Corrected the hero phoenix presentation by containing/cropping the baked-in circular title artwork instead of letting it dominate the mark.
- Kept the supplied JYC logo assets; no synthetic logo artwork was generated.
- Added a live/ready status rail in the hero based on published event data.
- Tightened hero typography, spacing, chips, orbital layers and information hierarchy.
- Improved focus states, touch targets and reduced-motion behavior.
- Preserved published-content-only behavior and existing platform/admin routes.

## Research-informed principles
- Primary navigation stays within a compact top-level set; secondary destinations belong in More.
- JYC is treated as a student ecosystem: clubs, events, people, moments, discovery and participation.
- Visual language combines JYC red/gold, restrained glass surfaces, editorial typography and campus-specific microcopy.

## Content note
Default empty-state copy uses only facts supported by JIIT's published student-club material. Counts, clubs, events, people and gallery items remain database-driven and are not fabricated.
