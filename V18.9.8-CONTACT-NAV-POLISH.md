# JYC Website V18.9.8 — Contact + Navigation Polish

- Removed Fests and Recruitment from primary navigation.
- Fests are now public only when the site is switched into `fest` mode by an authorized super admin.
- Recruitment is no longer a public navigation/search destination; the homepage can surface one recruitment tile only when the `recruitmentHub` flag allows it and a club has recruitment open.
- Added Contact as a primary desktop navigation item and a polished Contact page with JYC Instagram, WhatsApp and email channels.
- Search keeps exact-title relevance first and no longer indexes hidden Fests/Recruitment destinations.
- Added dependency-free motion polish inspired by open-source micro-interaction patterns.
- Added a System & Platform control for Standard JYC / Fest mode.
