# JYC V18.17.0 — UI + Functional Refinement

V18.17 keeps the V15-style editorial JYC homepage while removing the visual and navigation regressions found in the latest mobile/desktop review.

## Public experience

- One Phoenix composition on the homepage; the duplicated ecosystem Phoenix is removed.
- Phoenix navigation is a compact three-door rail: Clubs, Events, Team.
- No scattered orbit/node layout on mobile.
- Homepage is shorter by default: Events → About → Clubs → Moments → CTA.
- The homepage Moments preview is limited to three images and links to the full archive.
- The duplicated Moments section is removed.
- Hero decorative chips and side notes are removed to reduce visual noise.
- Desktop primary navigation now exposes Clubs, Events, Moments, Team and Calendar.
- More contains only secondary destinations; it does not repeat Moments or Calendar.
- More locks page scroll, restores focus safely, closes on Escape and keeps the pointer visible.
- Search and overlays receive the same cursor/z-index treatment.
- Mobile remains the first layout, with compact Phoenix sizing and no continuous motion.

## Control Center

- Overview is no longer visually dominated by the AI Navigator.
- AI Navigator is available inside individual admin workspaces rather than the Overview surface.
- Admin guide defaults to collapsed for a calmer workspace and uses a versioned preference key.
- Admin content has a bounded readable width, consistent type scale, spacing and controls.
- Desktop sidebar remains fixed/readable while the main area gets the remaining width.

## Reliability

- Service-worker cache bumped to `jyc-cache-v18-17-0-ui-functional`.
- Package version is `18.17.0`.
- Added V18.17 static UI/functional QA contract.
- Browser QA suite updated for the current product contract.
- Existing V18.13 build preflight remains part of the release gate.

## Open-source reference patterns

The overlay/focus behavior follows the same general accessibility principles used by open-source component systems such as Radix Primitives and shadcn/ui: modal surfaces trap focus, prevent accidental background interaction and restore predictable keyboard behavior. The implementation remains native React/CSS so the JYC bundle does not gain a new UI dependency.
