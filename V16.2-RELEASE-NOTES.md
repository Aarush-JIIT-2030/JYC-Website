# JYC Website V16.2 — IIT-Inspired Campus Experience

This release focuses on making JYC feel more like a useful campus platform rather than only a visual club website.

## Product inspirations

- IIT Bombay InstiApp → unified discovery of organizations, events and people.
- IIT Roorkee Campus Dashboard → one campus feed for events and deadlines.
- IIT Kanpur → student-centric campus life, clubs, events and utility navigation.
- IIT Madras → campus life as a continuous mix of academic, co-curricular and extracurricular activity.

## Main improvements

- JYC Campus Feed
- Functional Phoenix navigation nodes
- Moments node added to Phoenix
- Improved loading experience
- Staged loading status
- Richer micro-interactions
- Better focus/keyboard accessibility
- Search result entrance animation
- More menu entrance animation
- Improved event/club card motion
- Footer signature polish
- Reduced-motion safeguards

## Engineering

- No Supabase schema changes required.
- Existing data model is reused.
- Version: 16.2.0
