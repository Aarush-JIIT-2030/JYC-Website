# JYC Website V18.2 — Production Readiness

V18.2 is the final pre-deployment hardening pass. It does not add new product features.

## Product core

The site remains centered on JIIT Youth Club (JYC): clubs, student communities, events, fests, moments, recruitment, projects and campus participation.

## Discoverability targets

Primary search families:
- JIIT Youth Club / JYC JIIT / JIIT Youth Club Noida
- JIIT clubs / JIIT Noida clubs / JIIT club list / JIIT student clubs
- JIIT events / JIIT campus events / JIIT event calendar / JYC events
- JIIT fests / JIIT fest / JIIT annual fest / JIIT cultural fest / JIIT technical fest
- Impressions JIIT / Converge JIIT
- JIIT club recruitment / JIIT club auditions / how to join JIIT clubs

These are represented in relevant page titles, descriptions, visible content, internal links and structured data rather than being dumped into every page.

## V18.2 hardening

- Unknown SPA routes are marked `noindex` to reduce accidental indexing of arbitrary rewritten URLs.
- Event structured data no longer invents an end time when the event has no end time.
- Breadcrumb schema correctly identifies `/fests` as Fests.
- Vercel CSP no longer hard-codes one Supabase project reference.
- Sitemap generation automatically adds the absolute sitemap URL to `robots.txt` when `VITE_SITE_URL` is configured.
- No placeholder production sitemap is committed.

## Deployment sequence

1. Set `VITE_SITE_URL` to the real public JYC domain.
2. Set production Supabase public URL/key and any required VAPID public key.
3. Run `npm run qa`.
4. Run `npm run qa:production`.
5. Run `npm run seo:sitemap`.
6. Run `npm run build`.
7. Deploy the generated app.
8. Verify `/robots.txt` and `/sitemap.xml`.
9. Add/verify the production property in Google Search Console and submit the sitemap.
10. Use URL Inspection/Rich Results testing on the home page, a club page and an eligible public event page.
11. Run browser/mobile QA and production Supabase RLS tests.

Google recommends sitemap submission and URL Inspection after deployment; event pages need unique URLs and accurate event markup, while Organization markup can help Google understand and disambiguate the organization.
