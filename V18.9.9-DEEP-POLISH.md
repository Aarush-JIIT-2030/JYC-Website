  - official JYC WhatsApp community

## Product cleanup

Removed dead or redundant public code that no longer represented the club-first product:

- unused `InteractivePhoenix` import
- unused `JYCPulse` component
- unused public `DownloadPage` (legacy `/download` now redirects to the JYC Guide)
- unused notification-center UI and push-subscription helper

## Open-source UI references

The interaction language was reviewed against open-source component ecosystems including:

- React Bits — animated, customizable UI and micro-interaction patterns
- shadcn/ui — accessible component and focus-state conventions

No new animation runtime was added for these effects. JYC keeps the implementation CSS-first to reduce dependency and bundle overhead.
