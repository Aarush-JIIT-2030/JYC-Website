# JYC Website V18.0 — Final Product Pass

V18 is the final product-completion pass before production deployment/QA.

## Changes
- Added visible breadcrumb navigation on key public content pages.
- Added a content-first JIIT Youth Club topic panel on the homepage linking to Clubs, Events, Fests, Projects and the student guide.
- Switched public club/event detail links to human-readable slugs. Existing ID URLs remain resolvable and canonicalize to the slug URL.
- Added slug-based canonical metadata and event registration paths.
- Added descriptive club-logo alt text and retained lazy loading.
- Added Fests to the public footer navigation.
- Added responsive breadcrumb/topic-link styling with reduced-motion-friendly behavior.
- Added final static product QA.

## Verification
- `npm run qa` passes all static/product checks.
- Production `npm run build` still requires the Vite package to be installed; this environment has no cached Vite tarball, so build execution is intentionally reported separately rather than claimed as passed.
