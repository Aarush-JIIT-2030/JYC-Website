# JYC V18.3 — Final UI Simplification & Student-First Pass

## Product direction
JYC remains the core product: JIIT Youth Club clubs, events, fests, recruitment, campus participation, My JYC and staff operations.

## Removed from the visible product
- Discover as a primary desktop feature; `/discover` redirects to `/clubs`.
- Projects / student-project submission UI; legacy project URLs redirect to Clubs.
- Moments as a primary feature; legacy `/moments` redirects to Gallery.
- Separate My Agenda page; `/agenda` redirects to My JYC and the agenda is integrated into My JYC.
- "New to JYC?" utility card from More.
- Student-work-for-review language.

## Navigation changes
- Desktop primary navigation is now Home, Clubs, Events, Fests, Team, More, Search.
- More is a centered command panel on desktop and a bottom sheet on mobile.
- Staff Control Center is discoverable from both More and Search.
- Search is focused on clubs, events, fests, people and useful student routes.

## Homepage/UI
- Phoenix uses the sharper transparent JYC phoenix asset.
- Phoenix stage height was tightened to remove the large dead area below the bird.
- Hero stats now show Clubs, Team, Upcoming and Fests.
- Hero quick actions now include Recruitment instead of Moments.
- Homepage layout is intentionally limited to Events, About JYC, Clubs and a compact centered closing CTA.
- Closing CTA is short, centered and visually contained.
- JYC logo lockup received a cleaner gold/red framed treatment.
- More/Search controls explicitly restore pointer interaction and caret behavior.

## My JYC
- Saved-event agenda is now part of My JYC.
- Added agenda list and `.ics` export directly inside My JYC.
- No separate agenda page is required.

## Student Guide
The guide now links students to:
- JIIT Shelf for organised academic resources, lectures, tutorials, PYQs and study tools.
- JIIT Pulse for attendance, schedules and mess information across Sector 62 and Sector 128.
- Official JIIT for university-level notices and academic information.

## Verification
- `npm run qa` passes all current static, release and SEO checks.
- A fresh Vite production build was not run in this model environment because Vite is not installed in the local execution cache. The project had previously built successfully in the user's Windows environment before this UI pass; run `npm run build` locally after extracting this release.
