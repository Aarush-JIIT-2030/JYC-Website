# JYC V14.5 — Final Platform Pass

This release consolidates the V14.0 interaction pass, V14.1 platform pass and V14.2 experience platform into a broader public student ecosystem.

## Included
- Dynamic published-data counters with one-time viewport count-up.
- Magnetic five-item mobile bottom navigation.
- Pill-shaped search, filters and calendar/card controls.
- Pointer/touch-safe depth and 3D tilt treatment.
- Optional Spline Phoenix scene URL with a JYC-native CSS fallback.
- Interactive ecosystem orbit.
- JYC Discover based on published club metadata.
- JYC Moments editorial archive.
- JYC Projects and Achievements indexes derived from published club data.
- Personal My JYC Agenda for saved events.
- Agenda `.ics` export and Google Calendar links.
- Local reminder preferences for saved events.
- Campus Map.
- Public certificate verification.
- Event QR sharing and printable QR view.
- Digital Fest Pass.
- Recruitment, auditions, notifications, registrations and account flows.
- Fest Mode and live programme architecture.
- Admin analytics, activity/audit history, version snapshots, role-based workspaces, reviews, registrations, backups and feature flags.
- Footer-only admin access; Admin is not exposed in the primary navigation.
- CMS-controlled JTV URL; no invented JTV destination.
- Experience settings for performance and motion preferences.
- PWA/offline support, connection/error states, SEO metadata, JSON-LD and `llms.txt`.
- Reduced-motion and low-performance-device handling.
- Accessibility-oriented focus/labels and motion safeguards.
- Public content schema and structured content pipeline documentation.
- Self-host/download documentation and public deployment guidance.

## Content rule
No synthetic clubs, people, events, achievements, projects or photographs are introduced as official JYC content. Empty states intentionally remain empty until administrators publish real records.

## Data additions
All new platform-facing fields are optional and existing payloads remain compatible:
- `homepage.phoenixSceneUrl`
- `homepage.jtvUrl`
- `campusMap.mapUrl`
- `campusMap.locations[]`
- `certificates[]`
- `club.projects[]`
- `club.achievements[]`

## Verification
Run:

```bash
npm install
npm run build
```

Then test desktop/mobile routes, light/dark mode, keyboard navigation, reduced motion, low-performance mode, admin role access, Supabase reads/writes, PWA installation, QR links, certificate verification and event registration.

The packaging environment could not complete a clean npm registry install, so this release must not be described as production-build verified until `npm run build` succeeds locally or in CI.
