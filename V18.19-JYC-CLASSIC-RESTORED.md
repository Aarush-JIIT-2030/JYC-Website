# JYC Website V18.19.0 — Classic Restored + Motion Polish

V18.19 restores the compact public JYC experience from the stronger V17/V15-era composition instead of replacing it with a large experimental landing page.

## Restored

- Full homepage hierarchy: Hero, JYC Pulse, Next Moment, Impact, Ecosystem, Moments, About, Activities, Clubs, Events, Archive, Gallery and CTA.
- Compact `Find your space.` clubs experience with type/category/interest filters.
- Phoenix-centered JYC identity and the orbital ecosystem composition.
- Subtle night-sky stars and light-mode atmospheric treatment.
- Restrained Phoenix/bird motion and orbital rings.
- Existing My JYC saved-event workflow and calendar actions.
- JYC Planner route (`/planner`) using the existing CalendarPage data model.

## Preserved from V18.18

- Global search and exact/brand search priority.
- SearchAction structured data.
- Safe external URL handling.
- Supabase publishable-key-only frontend boundary.
- CSP/security headers and JSON-LD escaping.
- SEO sitemap/robots metadata.
- Admin remains a separate private control surface.

## Motion approach

The motion layer uses lightweight local React/CSS patterns inspired by the current React Bits catalogue: restrained text/section reveals, magnetic-style hover feedback, orbit layouts, scrolling rails and marquee-like motion. The implementation does not add a large React Bits runtime dependency.

## Mobile-first rules

- 390×844 and 400×580 are primary public breakpoints.
- Headings remain compact.
- Phoenix motion is simplified on small screens.
- Custom cursor is not used on touch devices.
- `prefers-reduced-motion` disables continuous motion.
