# JYC V18.24.0 — Human JYC Final

V18.24 is a compact UI/UX repair pass built on the V18.23 public website.

## Focus
- mobile-first compact public UI
- connected Phoenix ecosystem navigation
- contained orbital identity
- night-sky dark mode and JYC paper light mode
- flying Phoenix theme transition
- inline My JYC account sync
- device calendar + Google Calendar planning
- About JYC quick answers instead of a separate FAQ page
- compact, readable Control Center
- no V18.18 motion layer
- reduced motion support

## Validation
Run:
`npm run qa`
`npm run build`
`npm run qa:browser`
