# JYC V14.7 — Final UI / Senior Feedback / Navigation Pass

## Primary fixes
- Fixed mobile theme toggle placement: it stays in the top header instead of floating below it.
- Fixed mobile More sheet stacking: it now sits above the fixed five-item dock and reserves safe-area space.
- Fixed Team search/filter collision with a dedicated pill search field and horizontally scrollable role pills.
- Reworked empty states into editorial, full-width sections with separators rather than isolated translucent boxes.
- Added subtle separators between homepage sections for stronger visual rhythm.
- Replaced the small header/admin/loading logo treatment with the supplied clean phoenix mark asset.
- Homepage counters are fully data-driven and display no misleading `0+` when the live value is zero.

## Admin Control Center
- Added collapsible desktop sidebar rail with persisted state.
- Added breadcrumb/current-workspace context.
- Strengthened admin visual hierarchy and sticky workspace header.
- Improved admin login branding and staff context.
- Preserved role-based workspaces, guides, reviews, registrations, versions, activity, system controls and preview.
- Public admin access remains footer-only, matching the senior instruction.

## Loading / reload experience
- New phoenix-led boot screen with grid, orbit rings and status rail.
- Reduced-motion safe.
- Keeps the initial experience branded without blocking the application indefinitely.

## Research-informed product patterns
- Compact primary navigation and secondary More menu inspired by current mobile/desktop navigation guidance.
- Grouped/collapsible admin sidebar inspired by modern open-source dashboard patterns.
- Event/project/resource-oriented information architecture informed by CICR, ARIES IIT Delhi, JIIT Pulse, GDGoC chapter platforms and open-source student-community portals.

## Preserved
- Dynamic Supabase-backed clubs/events/team/gallery data.
- Draft → preview → publish workflow.
- Fest Mode.
- Spline-ready Phoenix integration.
- 3D card tilt, magnetic mobile dock, pointer glow and staggered reveals.
- Light/dark mode.
- Reduced-motion and low-performance modes.
- JTV configurable external link.
- Footer-only staff/admin access.
- Self-host/download/PWA support.
