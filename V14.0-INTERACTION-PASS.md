# JYC V14.0 — Senior Feedback + Interaction Pass

Implemented:
- pill-first search, filter and segmented controls
- team search/filter layout that cannot collide
- dynamic homepage counters sourced from published content
- one-time viewport count-up animation with reduced-motion fallback
- magnetic mobile bottom-navigation active pill with spring-like CSS motion
- desktop 3D pointer tilt for club, event and team cards
- layered 3D perspective around the JYC hero/orbits
- pointer-following hero liquid glow using JYC red/cream palette
- cleaner editorial empty states without isolated giant translucent boxes
- subtle separators between homepage information sections
- admin entry hidden from primary navigation and exposed subtly in footer
- optional configurable JTV external link via `homepage.jtvUrl`
- safe-area-aware More sheet above mobile navigation
- staggered entrance motion with reduced-motion support

Design guardrails:
- no fake clubs/events/team data
- no rainbow gradients or excessive glassmorphism
- no 3D effect on every surface
- mobile remains touch-first and accessible
