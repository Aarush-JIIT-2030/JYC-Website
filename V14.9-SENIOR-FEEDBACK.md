# JYC V14.9 — Senior Feedback Pass

## Direct fixes from the supplied mobile review
- Fixed the mobile bottom navigation so it remains a true rounded pill with a persistent sliding active indicator.
- Kept the dock fixed to the viewport and raised its stacking context so it cannot randomly become static or square.
- Rounded all four corners of the mobile More sheet and separated it from the bottom viewport edge.
- Removed card-like backgrounds from empty Discover/Moments states; empty states now read as editorial content rather than a disabled panel.
- Reworked the ecosystem/brand visual so the phoenix lockup is controlled and does not become a stretched/misaligned circular logo.
- Replaced the blurry phoenix crop used in the public header with the higher-resolution official circular JYC seal.
- Reused the same circular seal for the admin/loading brand treatment.
- Hardened the reveal system so content remains visible after it has entered the viewport and after navigation/state changes.
- Disabled lazy-image `content-visibility` collapsing for JYC images to avoid revisiting a section and seeing a blank surface.

## Product direction retained
- No fabricated clubs, events, people, achievements or gallery content.
- JTV remains configurable and external until the official JTV site is available.
- Admin access remains subtle rather than a primary public navigation item.
- Motion/performance and reduced-motion support remain enabled.

## QA focus
Test on 390px and 360px mobile widths:
1. Home -> scroll down -> scroll back up.
2. Home -> Clubs -> Home.
3. Open More -> close More -> open More again.
4. Confirm all four More-sheet corners are rounded.
5. Confirm the bottom dock is always a rounded pill when the hamburger drawer is closed.
6. Change light/dark theme and confirm dock remains intact.
7. Open Discover with zero clubs and confirm there is no giant card background.
8. Inspect the ecosystem logo at multiple scroll positions.
