# JYC Website — V18.9.5 JYC-First Product Pass

This pass is focused on the core JIIT Youth Club experience rather than adding more platform surface area.

## Public experience
- Removed Discover as a public product feature; `/discover` remains only as a compatibility redirect to `/clubs`.
- Removed Fest Mode integration from the public shell and Control Center navigation. The existing public Fests page remains a normal content page.
- Restored a three-Phoenix JYC core: Clubs, Events and My JYC.
- Replaced the logo mark in primary navigation/footer/admin branding with the bird-only Phoenix asset.
- Made the JYC story card clickable.
- Removed the duplicate Recruitment placement from More.
- Moved supporting JIIT tools lower on the homepage so JYC clubs/events remain the visual priority.
- Added JYC Clubs, Campus Map, JIIT Pulse, JIIT Shelf and Official JIIT as supporting tools.
- Removed the homepage "Find your space" framing in favor of an explicit JYC Clubs section.
- Improved light-mode surfaces, bird motion, card hover behavior and atmospheric depth.

## Tutorial
- Tutorial is now a fixed viewport modal instead of participating in page scroll.
- It navigates through Clubs → Events → My JYC → Campus Map → More.
- Each step explains the actual website while navigating to the corresponding page.
- Uses the Phoenix as the guide mark and respects reduced-motion preferences.

## Calendar
- Calendar can open with JYC + academic dates together when academic dates are enabled for the combined view.
- Added My saved filtering.
- Saved JYC events are visually marked in the calendar.
- Added Google Calendar actions for JYC events.

## Campus Map
- Added a campus summary/control layer.
- Venue search can be cleared directly.
- Campus switching clears stale search/selection state.
- Directions remain available from the summary and campus panels.

## Admin
- Admin sidebar now uses readable workspace names instead of collapsed single-letter-looking labels.
- Removed Fest Mode from roles, navigation, command search and overview workspace cards.
- Reorganized the sidebar into Overview, Content, Campus & Operations, and System.
- Interactive Admin Tutorial now filters steps to the administrator's actual permissions.
- Added a real `admin-management` Edge Function health action and wired it into System & Platform health checks.

## QA
- Existing V18.9 static QA: PASS.
- New JYC-first QA: PASS.
- Search QA: 5/5.
- Service-worker cache namespace bumped to `jyc-cache-v18-9-5-jyc-first`.

## Design references
The information architecture was informed by public student-activity patterns such as IIT Bombay's Students' Gymkhana / InstiApp, where the student activity hub connects organizations, events and people, and BITS Pilani's student activity pages, which separate clubs, activities and campus facilities rather than making every service part of the same feature.
