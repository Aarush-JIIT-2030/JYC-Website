# JYC V17.1 — Security & Operations Hardening

This is a reliability pass, not a new feature dump.

## Changes
- Transactional `jyc_register_for_event` RPC serializes capacity checks per event.
- Native registration validates publication state, deadline, duplicate email and waitlist/capacity state server-side.
- Frontend native registration uses the RPC rather than direct table inserts.
- Push subscriptions are account-owned; anonymous client rows are no longer readable/updatable.
- Added an executable Playwright smoke suite.
- Added production Supabase environment validation.
- Release QA checks the registration RPC and push privacy policy.

## Required production migration
Run `supabase/V17.1-SECURITY-OPERATIONS.sql` against the connected production Supabase project after the existing production bootstrap/repair migrations.
