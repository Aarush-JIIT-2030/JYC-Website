# JYC Website V17.4 — Discoverability & Experience Upgrade

## Product goal
Make JYC the strongest canonical public destination for relevant JIIT student-life searches while improving the existing experience rather than adding unnecessary product complexity.

## Search/discoverability
- Route-specific page titles and descriptions for public pages.
- Homepage title targets the natural query cluster: JIIT Youth Club, clubs, events and fests.
- Dedicated `/fests` landing page for officially published fest/flagship-event records.
- Dynamic canonical URLs for public pages.
- Open Graph/X metadata with the Phoenix social image.
- Organization + WebSite + BreadcrumbList structured data.
- Event structured data on individual event pages.
- Club Organization structured data on individual club pages.
- Public routes indexable; account/admin/utility routes are marked noindex.
- `robots.txt` keeps private areas out of crawl paths.
- `llms.txt` documents canonical public JYC routes and search terminology.
- Build-time sitemap generator supports published club/event URLs when Supabase public build variables are available.
- Added non-JavaScript public navigation/content in the initial HTML.
- Service-worker cache namespace updated for the release.

## Existing-feature improvements
- Preserved the V17.3 simplification pass instead of adding homepage clutter.
- Kept Follow Club and Save Event as distinct concepts.
- Event pages remain the canonical destination for event details, registration, saving, calendar, sharing and QR actions.
- Fests are a discoverability layer over existing event records, not a second event system.

## Production SEO setup
Set `VITE_SITE_URL` to the real production origin and run:

```bash
npm run seo:sitemap
```

Then submit `/sitemap.xml` through Google Search Console after deployment. Search ranking itself cannot be guaranteed; the release improves crawlability, page understanding, internal linking, structured data and result presentation.
