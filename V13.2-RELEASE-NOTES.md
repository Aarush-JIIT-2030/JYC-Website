# JYC V13.2

Reference-inspired UI and reliability pass.

- Public mobile dock is portal-mounted, hidden on desktop, and fixed to the phone viewport bottom.
- Search is a translucent JYC command surface with improved mobile behaviour.
- Nested card controls no longer bubble into card navigation (e.g. Save buttons).
- Client analytics is opt-in with `VITE_ENABLE_ANALYTICS=true`; default false avoids telemetry requests before deployment.
- Admin labels use non-truncating layout rules; role-scoped workspaces remain.
- Light/dark mobile glass, safe-area spacing, focus states and reduced motion refined.
- Homepage hero/logo/orbits and event rail tuned toward the supplied reference composition.
- No “This Week at JYC” section added.
