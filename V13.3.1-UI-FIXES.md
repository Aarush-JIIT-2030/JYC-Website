# V13.3.1 UI fixes

- Mobile public navigation is now explicitly five destinations: Home, Clubs, Events, Team, More.
- Gallery, About, Calendar, Recruitment, Auditions, My JYC, Notifications and Admin remain inside More.
- Desktop never renders the mobile dock.
- Mobile desktop-nav links are explicitly hidden unless the hamburger menu is open, preventing ghost/overlapping labels.
- Mobile top chrome follows the supplied reference: compact pill-like header, circular JYC mark, search, and menu.
- Mobile bottom navigation is fixed to the bottom with safe-area support and JYC glass styling.
- Search is a translucent mobile sheet with horizontal exploration chips and larger touch targets.
- Hero typography and phoenix/orbit composition are tightened for phones.
- Reduced-motion behaviour remains respected.
- No “This Week at JYC” feature was added.
