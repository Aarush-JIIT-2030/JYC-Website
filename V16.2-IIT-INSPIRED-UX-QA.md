# JYC V16.2 — IIT-Inspired UX + QA

## Research basis

The product pass takes structural inspiration from current IIT student/campus platforms rather than copying their visual identity:

- IIT Bombay InstiApp: a unified front page for student activities, with organizations, events and people discoverable together.
- IIT Roorkee Campus Dashboard: a single feed that consolidates campus events, clubs and registration/deadline information.
- IIT Kanpur student/campus pages: student-centric entry points, events, clubs/communities, campus utility and quick access to practical information.
- IIT Madras: campus life presented as a living stream of academic, co-curricular and extracurricular activity.

## V16.2 changes

### Home
- Added **JYC Campus Feed**.
- The feed prioritizes a live event, next event, recruitment, latest moment, club discovery or campus map depending on the real published data available.
- No fake metrics/content are generated.
- Existing JYC Pulse, countdown and ecosystem sections remain intact.

### Phoenix
- Phoenix ecosystem nodes are now actual buttons.
- Added **Moments** as a fourth route.
- Hover/focus states expose an action hint.
- Nodes route to `/clubs`, `/events`, `/team`, and `/gallery`.
- Reduced-motion users retain the same functionality without animation dependence.

### Loading
- Added staged boot messaging and progress indication.
- Improved depth, orbit, grid, glow and logo motion.
- Added accessible `role=status` / live messaging.
- Loading remains short and does not intentionally delay application data beyond the existing boot guard.

### Navigation/UI
- Added tactile focus states and richer hover transitions.
- Added subtle navigation edge animation.
- Search results animate in progressively.
- More panel sections animate in sequentially.
- Footer has a low-contrast oversized JYC signature layer.
- Added shimmer treatment to key information strips.

## Functional QA performed

Static/runtime-independent checks completed in this environment:

- All source files referenced by the new CSS import exist.
- All public image assets referenced by the changed components exist.
- All new navigation destinations already exist in the router.
- The existing event/club/team/gallery data paths are reused; no schema migration is required for V16.2 UI changes.
- JavaScript-only helper modules were checked with Node syntax checking.
- Shell deployment scripts were checked for basic file references.
- Package version bumped to 16.2.0.

## Build limitation

A full Vite production build could not be executed in the isolated environment because `node_modules` was not available and npm registry installation timed out. Therefore this release does **not** claim a completed Vite build in this environment.
