# V18.9.9 — Runtime Fix / White Screen Fix

This is a corrective rebuild of V18.9.9.

## Fixed
- Restored the missing `EventTools` named export from `src/extra-features.jsx`.
- Restored the missing `DownloadICS` named export from `src/extra-features.jsx`.
- Added a runtime-contract QA check that verifies every named import from `extra-features.jsx` has a matching export.
- Kept the existing Fest Mode and recruitment gating fixes intact.

## Why the white screen happened
Vite could parse `main.jsx`, but the browser module loader then failed because `main.jsx` imported `DownloadICS` (and `EventTools`) while the deep-polish build had removed those exports. React therefore never mounted and the page remained blank.

## Verification
- `npm run qa` passes, including the new runtime contract check.
- A fresh local Vite/browser run is the final authority for runtime behavior.
