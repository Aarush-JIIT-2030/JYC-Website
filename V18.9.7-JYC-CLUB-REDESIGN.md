# JYC Website V18.9.7 — Clubhouse Redesign

## Product direction
The public website is now explicitly designed as the official **JIIT Youth Club** website, not as a general student utility/dashboard platform.

### Public hierarchy
- About JYC
- Clubs
- Events
- Fests
- Team
- Gallery
- Recruitment
- Calendar
- My JYC (optional saved items)
- JYC Guide
- Contact

## Removed / de-emphasized
- Discover as a public feature (legacy route redirects to Clubs)
- Student-tool/resource portal framing
- JIIT Shelf / JIIT Pulse promotion
- Achievements and Experience Settings as public destinations (legacy routes redirect to About)
- Student-dashboard language in the public guide
- Fest Mode as a separate site mode

## Phoenix / bird system
- Navigation uses the bird-only Phoenix mark.
- Interactive Phoenix no longer uses the text-bearing Phoenix artwork.
- Homepage hero uses a primary bird, ghost bird, shadow and flight trails.
- Three Phoenix cards are functional: Communities, Experiences, People.
- Motion is CSS-native and respects the existing reduced-motion architecture.

## Tutorial & Guide
- First-visit tutorial is viewport-fixed and cannot become page scroll content.
- Tutorial navigates through real JYC pages.
- JYC Guide is a club handbook focused on communities, experiences, recruitment, people, gallery and optional saved items.

## UI
- Editorial club-style hierarchy rather than dashboard-style utility cards.
- Stronger JYC identity, typography, Phoenix motion and story sections.
- More sheet is a JYC directory with context instead of a utility drawer.
- Light mode uses warm paper tones and restrained JYC red/gold atmosphere.
