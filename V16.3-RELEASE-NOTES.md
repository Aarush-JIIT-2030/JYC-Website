# JYC Website V16.3 — Functional QA + Campus Utility Pass

## Product direction

V16.3 takes the useful structural ideas visible in current IIT student platforms and applies them to JYC without copying their visual identity:

- IIT Bombay InstiApp: organisations, events and people as one connected discovery layer.
- IIT Roorkee Campus Dashboard: one feed, followed clubs, reminders, notifications and a calendar-oriented campus utility.
- IIT Kanpur: clubs/communities, events and practical campus-life utility in one student-facing experience.
- IIT Madras: broad club/community discovery across technical, cultural and extracurricular participation.
- JIIT OSDC: beginner-friendly open-source participation, workshops, projects and contribution pathways.

## Changes

### Functional
- Campus Feed now personalizes around locally saved clubs and events.
- A followed/saved club can surface its next published event in the home feed.
- Saved events can surface as a direct My JYC action.
- Feed now has a clear “Make it yours” / “Your JYC” route.
- Google Calendar date formatting was hardened for both `09:00` and `9:00` inputs.
- Native calendar generation was hardened for malformed/missing times.
- Local event reminders can survive beyond the browser's single `setTimeout` limit by re-arming in chunks.

### Loading
- Boot screen is now driven by real app state rather than an artificial four-step timer.
- Cached and uncached startup states are distinguished.
- Offline startup has its own state.
- Progress steps reflect actual boot stages.
- Minimum visual dwell is retained so the identity transition does not flash.

### Performance
- Removed always-on `will-change` pressure from large card collections.
- Touch devices no longer pay desktop hover/tilt costs.
- Mobile blur layers are reduced.
- Added font preconnects and Supabase DNS prefetch.
- Service-worker cache name bumped to V16.3 so old shells are invalidated cleanly.

### QA tooling
- Added `npm run qa`.
- Static QA checks package/lock versions, required files, CSS imports, routes, public assets, private-key markers, CSS block balance, helper-module syntax, service-worker cache version and performance hints.
- Pure utility smoke tests cover saved-state behaviour and Google Calendar date generation.
