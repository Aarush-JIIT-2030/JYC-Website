# V18.10 — Best of Previous Releases

This release consolidates the strongest working JYC features from the earlier V13–V18 platform passes instead of removing them.

## Restored / repaired
- Team route/runtime
- Club detail pages
- Gallery + lightbox
- Event share tools
- JYC Assistant
- Admin management workspaces: homepage, team, gallery, categories, calendar, platform, admins, notifications and fest controls
- Admin event publishing flow compatibility

## Preserved
- Custom cursor
- Phoenix hero + three Phoenix doors
- Fest Mode gating
- Homepage-only recruitment
- Search exact-title priority
- JYC + academic calendar
- My JYC
- Event reminders, Google Calendar, ICS and QR
- Campus map
- Contact + creator details

## UI direction
The public site remains club-first. The visual language combines JYC's red/beige/gold system with editorial typography, restrained motion, depth and accessible focus states. Open-source UI references are documented separately.

## QA
Adds `qa-v18.10-best.mjs` to verify critical component/runtime contracts that static JSX checks previously missed.
