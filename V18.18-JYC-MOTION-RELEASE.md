# V18.18.0 — JYC Motion

V18.18 is a public-facing redesign built on V18.17.0. The goal is a site that feels authored by a JIIT student web team: energetic, animated and useful without becoming a generic AI/SaaS template or a React Bits demo.

## Public experience
- New motion-first JYC homepage with content-driven animation.
- Interactive club directory with hover/focus previews on desktop and touch-safe behavior on mobile.
- Event timeline with live/up-next state and featured event preview.
- Horizontal Moments rail with native touch scrolling.
- JYC Now status strip using published data only.
- JYC archive by published event year.
- Latest JYC activity/announcement list without invented news.
- Short, purposeful page micro-interactions and motion.
- Reduced-motion fallbacks and mobile-specific behavior.
- Search overlay remains keyboard accessible and now exposes the official JIIT Youth Club page first for brand queries.

## Discoverability
- Static Organization + WebSite structured data in `index.html`.
- Dynamic Organization, WebSite, BreadcrumbList, Event and Club JSON-LD.
- JSON-LD is escaped against `</script>` breakout.
- Canonical metadata and Open Graph metadata.
- Public sitemap and robots rules.
- `/guide` is treated as the JYC FAQ.
- SearchAction can open the site search using `/?q=`.
- Public content keywords are written around real JYC/JIIT entities rather than generic marketing copy.

## Security
- Frontend uses the Supabase publishable key only.
- Anonymous search does not expose the Control Center destination.
- Dynamic external links are validated to HTTP(S) before use in public content surfaces.
- Vercel security headers include CSP, HSTS, frame protection, MIME sniffing protection, referrer policy, permissions policy, cross-origin policies and inline-script-attribute blocking.
- Service worker caches only same-origin runtime assets.
- Added static security QA for browser-shipped secret patterns, headers and unsafe DOM usage.
- Added GitHub CodeQL workflow and a high-severity dependency audit gate in CI.

## Open-source inspiration
Patterns were evaluated from React Bits, Motion, Radix-style accessibility patterns and public university/student-club projects. Components are selectively implemented or adapted rather than copied wholesale, keeping the JYC codebase small and content-driven.

## QA
Run:

```bash
npm install
npm run qa
npm run qa:seo
npm run qa:security
npm run build
npx playwright install chromium
npm run qa:browser
```

The final production gate remains the developer machine/CI because dependency installation and browser execution must be verified in a real Node/browser environment.
