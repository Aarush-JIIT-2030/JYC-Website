# V18.5 — AI Admin Copilot

## What changed
- Every primary Control Center workspace now exposes an AI Content Copilot.
- Clubs, Events, Fest Mode, Homepage, Team, Gallery, Categories, Notifications and Campus Map pass their current draft into the copilot.
- Polish results can be applied back into supported drafts before saving.
- System, Reviews, Versions, Registrations and Albums have an AI workspace audit action.
- AI is explicitly advisory: administrators still review and publish changes.

## Supabase setup
Deploy the new Edge Function:

```bash
supabase functions deploy ai-content-assist
```

Set these Supabase Edge Function secrets:
- `OPENAI_API_KEY` — required; keep server-side only.
- `OPENAI_MODEL` — optional; defaults to `gpt-5.6-luna`.

The browser never receives the OpenAI API key. The Edge Function checks the authenticated user against `jyc_admins` before calling the model.

## Workflow
1. Administrator creates the initial draft.
2. Click **Polish draft**, **Quality check**, or **SEO pass**.
3. Review the suggested output.
4. Apply the draft where supported.
5. Preview the public page.
6. Save/publish through the existing role-based workflow.

AI must not be treated as a source of factual JIIT information. Missing facts are surfaced as suggestions rather than invented.
