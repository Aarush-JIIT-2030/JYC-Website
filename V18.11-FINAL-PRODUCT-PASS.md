# JYC V18.11 — Final Product Pass

V18.11 is the final product pass over the V18.10 foundation. It fixes the Vite-blocking `GalleryItems` redeclaration and concentrates on product coherence rather than feature sprawl.

## Public website
- Shared JYC editorial language across public surfaces.
- Clubs remain the community-first entry point.
- Events now has an editorial featured event, live/upcoming/past views, search, club filtering, date filtering and calendar mode.
- Club detail remains a mini identity: story, people, recruitment, events, gallery and social links.
- Team, Gallery, Calendar and Contact receive the same spacing, borders, motion and interaction language.

## Phoenix
- Pointer-reactive depth and tilt.
- Lightweight orbit rings and particles.
- Hover response on the three functional Phoenix doors.
- Reduced-motion support retained.

## Admin
- Existing management capabilities preserved.
- Editor tabs and action controls get clearer sticky positioning.
- Mobile action bar and workspace remain intact.
- AI remains optional and draft-first.

## QA
- Browser QA is now an explicit project dev dependency.
- Run `npm install`, then `npx playwright install chromium`, start Vite with `npm run dev`, and run `npm run qa:browser`.
