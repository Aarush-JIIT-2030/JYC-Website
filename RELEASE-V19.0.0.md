# JYC V19.0.0 — COMPLETE EXPERIENCE PASS

This release applies the requested JYC-wide improvement pass while intentionally **not adding a new Campus Pulse feature**.

## Product work
- Deep cream / brass / ink light-mode world with brass Phoenix treatment.
- Full-viewport Phoenix Flight theme transition with articulated SVG wings, body motion, flight path, trail and native View Transition API fallback.
- Today at JYC section using only published event data.
- JYC Archive for published events, clubs and gallery moments.
- Branded 404 route.
- Editorial gallery/moments treatment.
- Sticky desktop/mobile admin chrome and deeper Heritage admin UI.
- Neutral AI setup/error presentation; existing Edge Function remains server-side.
- Fest themes receive structural visual treatments rather than only palette swaps.
- Focus-visible and reduced-motion refinements.
- Route entrance transitions and service-worker cache bump.
