# JYC Website V27.1.0 — Editorial Pulse

## What changed

- Added a compact **JYC Pulse** status rail beneath the hero so visitors can immediately see live/upcoming activity, published clubs and recruitment windows.
- Activated the existing **JYC Journal** as the homepage's editorial storytelling layer instead of duplicating the older hub-story grid.
- Added a 12-column editorial journal layout with larger lead stories, compact supporting stories, responsive mobile stacking and reduced-motion support.
- Kept the V20-inspired split hero, beige/black/white visual system and logo-led identity intact.
- Rotated the service-worker cache to `v27-1-0` so the new shell is not trapped behind an older browser cache.
- Updated source QA and package/lock versions to `27.1.0`.

## Design direction

The upgrade follows the information rhythm observed on the official JIIT Innovation website: clear activity/status context, strong event discovery, archive-minded storytelling and visual documentation. The JYC implementation remains its own visual system rather than copying Innovation's interface.
