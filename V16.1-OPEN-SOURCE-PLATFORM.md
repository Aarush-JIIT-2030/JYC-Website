# JYC V16.1 — Open-Source Platform Pass

## Goal

Turn JYC from a visually strong club website into a more coherent student platform while keeping the existing JYC visual identity and Supabase architecture.

## Implemented

- Finalized the student-facing primary navigation: Home, Discover, Clubs, Events, Moments, Team, More.
- Kept Staff / Control Center out of the primary navigation.
- Staff access is now surfaced in **More** and **global Search only for an authenticated active admin session**.
- Removed the public staff-access footer action for non-admin visitors; the public footer now points beginners to the JYC Guide.
- Expanded More into grouped **Discover / Participate / Guide / Staff** navigation.
- Added `/guide` for beginner onboarding.
- Added `/resources` for guides, student builds, campus tools and an open-source contribution pathway.
- Added intent-aware search shortcuts for phrases such as `events tomorrow`, `sector 128`, `my registrations`, `guide`, and `open source`.
- Added authorized-admin search results for Control Center and the review inbox.
- Renamed the admin review workspace to **Inbox & Reviews** to emphasize the attention queue.
- Added responsive resource and guide UI while respecting the existing JYC tokens and reduced-motion behavior.

## Open-source research used

The implementation was informed by the current JIIT Open Source Developers' Community ecosystem as surfaced through FOSS United's JIIT community page: hands-on workshops and meetups, hackathons/jams, open-source contribution guidance, starter issues/project squads, and beginner-friendly participation.

Reference: https://platform.fossunited.org/c/jiit

The JYC implementation deliberately borrows the **interaction model and information architecture**, not OSDC branding or content.
