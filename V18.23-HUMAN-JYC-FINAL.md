# V18.23.0 — Human JYC Final

## Design direction

A compact, mobile-first JIIT Youth Club website. The public experience prioritises clubs, events, people, moments and practical navigation. Decorative motion is subordinate to content.

## Research used

- JYC official public site for club/event/community information architecture.
- CICR for compact community + event presentation.
- JIIT material for the role of JIIT Youth Club 128 and the broader student-hub ecosystem.
- React Bits for orbit, navigation, command-palette and restrained interaction patterns.
- Open-source student-organisation repositories for practical search, event and community patterns.

## Explicitly avoided

- giant landing-page typography
- duplicate navigation destinations
- dashboard-like public UI
- random blue/purple gradients
- decorative particle-heavy animation
- synthetic/fake club or event records

## Functional changes

- JYC Assistant ranking bug fixed.
- Assistant uses the same search relevance engine as global search.
- Club/event assistant routes prefer published IDs.
- Campus map is responsive and keeps map + venue information separate.
- Planner remains in More and search.

## Visual changes

- compact header and Phoenix mark
- compact hero
- compact ecosystem orbit
- night-sky constellations
- warmer light mode
- shared Phoenix motion language
- smaller public page heads
- mobile-first map and assistant
